### 🌐 最终网络拓扑结构

* **外部设备**：`192.168.117.5/24`（直连有线网卡）
* **Windows 宿主机**：`192.168.117.12/24`（有线网卡），通过 `WLAN 2`（Wi-Fi）连外网
* **WSL2**：`192.168.117.17/24`（独立桥接节点，网关指向 Windows `192.168.117.12`）

---

### 📋 完整配置全流程

#### 第一阶段：Windows 宿主机配置（只需配置一次）

1. **创建外部虚拟交换机（绑定有线网卡 `Enet`）**
   以**管理员身份**打开 PowerShell，执行：
   ```powershell
   New-VMSwitch -Name "WSLBridge" -NetAdapterName "Enet" -AllowManagementOS $true
   ```

2. **开启 Windows 的全局 IP 转发**
   ```powershell
   Get-NetIPInterface | Set-NetIPInterface -Forwarding Enabled
   ```

3. **开启 117 网段的原生 NAT 转发（实现借 Wi-Fi 上外网，且不篡改网卡 IP）**
   ```powershell
   New-NetNat -Name "BridgeNat117" -InternalIPInterfaceAddressPrefix "192.168.117.0/24"
   ```

---

#### 第二阶段：配置 WSL 启用桥接模式

1. **在 Windows 用户目录下创建/修改 `.wslconfig`**
   在 PowerShell 中直接运行：
   ```powershell
   @"
   [wsl2]
   networkingMode=bridged
   vmSwitch=WSLBridge
   "@ | Set-Content "$env:USERPROFILE\.wslconfig" -Encoding utf8
   ```

2. **重启 WSL 生效**
   ```powershell
   wsl --shutdown
   ```

---

#### 第三阶段：WSL 内部网络配置（IP、路由与 DNS）

打开 WSL 终端，依次执行：

1. **给 WSL 分配独立的局域网 IP**
   ```bash
   sudo ip addr add 192.168.117.17/24 dev eth0
   sudo ip link set eth0 up
   ```

2. **添加默认网关（指向 Windows 宿主机的 IP）**
   ```bash
   sudo ip route add default via 192.168.117.12 dev eth0
   ```

3. **配置公网 DNS 解析**
   ```bash
   sudo bash -c 'echo "nameserver 223.5.5.5" > /etc/resolv.conf'
   sudo bash -c 'echo "nameserver 114.114.114.114" >> /etc/resolv.conf'
   ```

---

#### 第四阶段：连通性验证

* **测试直连外部设备**：`ping 192.168.117.5`（同网段二层直连，延迟 <1ms）
* **测试直连 Windows 宿主机**：`ping 192.168.117.12`
* **测试外网连接与域名解析**：`ping www.baidu.com`
* **外部设备访问 WSL**：外部设备直接连 `192.168.117.17`，所有端口全部开放直接互通。
