#flashcards 
核辐射是指**由于放射性物质在衰变过程中释放出来的射线对环境和生物产生的照射或者电离辐射**。

| 核辐射 | 名称                   | 特性                                     |
| ------ | ---------------------- | ---------------------------------------- |
| α粒子  | ==氦核==                   | 电离能力强，但穿透力弱，一张薄纸就能挡住 |
| β粒子  | ==高能电子流==             | 电离能力相较粒子弱而穿透能力较强         |
| γ射线  | ==能量比较高的电磁波==     | 有很强的穿透性                           |
| 中子   | ==原子核中的一种中性粒子== | 更大的穿透性                             |
