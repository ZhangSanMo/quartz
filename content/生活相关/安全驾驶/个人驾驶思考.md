# 2025/02/23
- 当距离路口还有一段距离，绿灯只剩10S的时候，应当减速等下一个绿灯。（想抢绿灯没抢到，还急刹，容易造成追尾
- 不需要加速的时候，脚放到刹车上准备。（停车的时候误踩了油门，有点危险
- 下高速的时候提前5km准备变道至前后无大车的右侧车道
# 2025/03/05
- 注意观察路面刹车印子，这表明前方易发事故
- 根据与前车保持适当车距，当前方突然变道，这表明可能前方可能有障碍，需减速。如有空间可变道
# 2025/03/13
- 进入急弯前就需要进行刹车减速，而不是进入弯道后减速。在弯道刹车容易造成轮胎打滑，影响安全。
# 2025/03/17
- 堵车的时候没有人会让你，这个时候变道应该额外注意
- 转弯的时候，除了左转先看右，右转先看后之外，注意导流方向，如果左转或右转有几条车道，应该注意一起左转或者右转的车辆，因为方向可能有交错导致刮蹭
# 2025/03/25
- 经过危险路段转弯时应该左右调动身体观察A柱形成的盲区，之前在水泵厂撞上石墩可能也有这个原因
# 2025/03/28
- 超越车辆时，除了要把握前后的纵向距离，也要把握横向距离。特别是两车的体型差距大时，当他车是大货车时，大货车的气流可能会影响小车的行进，需要紧握方向盘把握方向。当他车是自行车时，小车的气流影响自行车的行进，导致自行车摔倒。
